# RISC-V RV32I Pipeline

This project implements a simple pipelined RISC-V RV32I processor in SystemVerilog. The design is split into the usual pipeline stages: fetch, decode, execute, memory, and writeback. It also includes instruction/data memory, a register file, control logic, and hazard handling.

The project is intended for simulation using Icarus Verilog. GTKWave can be used to inspect the generated waveform.

## Requirements

Linux (Ubuntu/Debian):

```bash
sudo apt update
sudo apt install iverilog gtkwave make
```

On other Linux distributions, install `iverilog`, `gtkwave`, and `make` using the distribution's package manager.

Windows:

The easiest option is to use MSYS2. In the MSYS2 terminal, install the required packages:

```bash
pacman -S iverilog gtkwave make
```

MSYS2 provides Icarus Verilog and GTKWave as packages, and GNU Make is also available.

## Build and Run

Clone the repository:

```bash
git clone https://github.com/singul4ri7y/riscv-pipeline-rv32i.git
cd riscv-pipeline-rv32i
```

Run the Makefile:

```bash
make
```

This compiles the SystemVerilog source files and runs the simulation. A VCD waveform file named `wave.vcd` is generated by the testbench.

To open the waveform in GTKWave:

```bash
gtkwave wave.vcd
```

To remove the simulation executable:

```bash
make clean
```
